Cozy Beans Café Menu

   A clean, responsive digital café menu built with basic HTML5 and CSS3. 


Features

   Responsive Design: Looks great on mobile, tablet, and desktop.
   Clean Layout:  Organized categories for coffee, tea, and pastries.
   Cozy Aesthetic:  Styled with modern web typography and warm colors.

Built With

   HTML5: Semantic structure.
   CSS3: Custom styling, layouts, and media queries.
